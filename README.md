# Team Noname 公式サイト

芝浦工業大学附属中学高等学校のロボットチーム「Noname」の公式ホームページです。

## 概要
- 鳥取ローバーチャレンジ（TRC）出場チーム
- TRC2026 ブリヂストン賞受賞

## 技術スタック
- HTML / CSS / JavaScript（静的サイト）
- Cloudflare Pages でホスティング

## デプロイ
このリポジトリは Cloudflare Pages と連携しています。  
`main` ブランチへのプッシュで自動デプロイされます。
